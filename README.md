# Cameron Moses — Frontend Software Engineer Portfolio v2.0.26

A terminal-inspired, editorial portfolio for Cameron Moses — a frontend software engineer based in San Diego, CA.

---

## Site Description

This repository is the source for my personal portfolio: a single hand-crafted `index.html` with inline CSS. It mixes a developer-centric terminal aesthetic with high-end editorial layouts, and it bridges my background in operations and client-facing roles at companies like Uber and Applied Materials with the frontend work I do now.

The page is static on purpose — one file, no framework, no build step — so the layout and motion stay fully under my control.

---

## Key Features

* **Terminal hero:** A CSS-styled terminal object that holds my developer profile, current focus, and core interests.
* **Selected Project Showcase:** A curated display of production-ready applications with tech tags and links to live demos and repositories (including Skinstric, Summarist, Ultraverse NFT Market, and Real Estate Tracker).
* **Experience Timeline:** A historical breakdown from real estate and advisory consulting into engineering through the Frontend Simplified track.
* **Contact & Network:** Quick-access links to my résumé (Word / `.docx`), GitHub, LinkedIn, and email.

---

## Tech Stack

This site is hand-crafted HTML and CSS. It is not a React, Next.js, Tailwind, or Framer Motion app.

### What this site is built with

* **HTML5 & CSS3:** Semantic layout, custom properties, and hand-written styles in a single file.
* **A little vanilla JavaScript:** Smooth-scroll for in-page anchors.

### What I build with (projects)

The stack section on the site is my working toolkit — React, TypeScript, Next.js, and related tools used in the selected projects — not the architecture of this portfolio itself.
